# 📊 **Stock Management System Project**

---

## 📌 **Summary**

This Stock Management System is a modern, fully GUI-based application designed to **streamline food inventory management** with an emphasis on efficiency, data integrity, and user-friendly operations. Developed using **Python Tkinter** and **Object-Oriented Programming (OOP)** principles, it integrates a normalized **SQLite database** to handle all key data aspects: suppliers, sales, stock, users, and more.

---

## 🗄️ **Database**

- 🗃️ Uses a **SQLite relational database**.
- 🔄 Fully normalized structure for **suppliers, sales, food products, categories, login details**, ensuring minimal redundancy.
- ⚡ Optimized for **efficient data storage and retrieval**.

---

## ✍️ **Core Features**

- ➕➖ Implements **CRUD operations** to create, read, update, and delete products, categories, suppliers, and other records.
- 🔍 Powerful **search features** enable rapid access to any record.
- 📁 Supports **CSV file uploads** (`sales.csv`) to **update stock levels** automatically based on sales data.
- 🔄 Auto-refresh of inventory data, charts, and reports after CSV import.

---

## 📈 **Dashboard & Reporting**

- 💷 Displays **total sales revenue (£)** dynamically.
- ⚠️ Interactive buttons show counts of **stocked out** and **reorder-needed items**.
- 📋 Clicking buttons opens a detailed **treeview** listing products and supplier details.
- 📧 Integrated **email panel** allows direct supplier communication for reordering.
- 📊 Visualizes data with **bar charts** showing sales per product (quantity & revenue).
- 🏆 Generates **performance reports** for top 5 best and worst performing products by quantity sold over defined time periods.

---

## 🔮 **Sales Forecasting**

- 📈 Implements **ARIMA forecasting models** for predicting product sales in upcoming periods.
- 🔮 Assists in proactive stock management based on predicted demand.

---

## ⚙️ **Additional Features**

- 🖥️ Fully **GUI-based** with Python Tkinter — clean, maintainable OOP code.
- 🔐 Supports **Two-Factor Authentication (2FA)** for secure system access.
- 🔄 Includes **password reset functionality** for user convenience.
